如何将管理工具改为中文界面：

1. 用记事本打开 start.ps1
2. 找到以下英文，替换为中文：

   "Ring Rush - Game Manager"  →  "Ring Rush - 弹棋 管理工具"
   "[1] Start Server"          →  "[1] 启动游戏服务器"
   "[2] Start Background"      →  "[2] 后台启动服务器"
   "[3] Install Dependencies"  →  "[3] 安装/更新依赖"
   "[4] Check Environment"     →  "[4] 环境检查"
   "[5] Open Browser"          →  "[5] 打开游戏页面"
   "[6] Check Port"            →  "[6] 查看端口占用"
   "[0] Exit"                  →  "[0] 退出"
   "Select [0-6]"              →  "请选择 [0-6]"
   "Starting server..."        →  "正在启动服务器..."
   "Starting background..."    →  "后台启动服务器..."
   "Server started"            →  "服务器已启动"
   "Done"                      →  "完成"
   "Environment Check"         →  "环境检查"
   "Deps OK"                   →  "依赖已安装"
   "Bye!"                      →  "再见！"
   "Invalid"                   →  "无效选择"
   "Press Enter"               →  "按回车键继续"

3. 保存时选择 "UTF-8" 编码（重要！）

4. 双击 start.bat 即可使用中文界面
